Wine für ChatGPT & Codex

Windows-Programme direkt ausführen.

Portable Wine Runner ist ein Skill-Plugin, das eine portable Wine-Laufzeitumgebung bereitstellt. Dadurch können kompatible Windows-Programme in geeigneten Linux-Umgebungen ausgeführt und getestet werden, ohne Wine jedes Mal vollständig neu einrichten zu müssen.

GitHub Repository Mehr erfahren

Prebuilt Wine

Eine vorbereitete Wine-Runtime ermöglicht einen schnellen Start ohne vollständige Kompilierung der Wine-Quellen.

Build-Fallback

Wenn die vorbereitete Runtime auf einem System nicht funktioniert, kann der Skill Wine aus den mitgelieferten Quellen neu bauen.

Kein eigener Server

Das Plugin ist als lokaler Skill aufgebaut und benötigt keinen eigenen MCP-Webserver oder externen Backend-Dienst.

Was macht das Plugin?

ChatGPT oder Codex kann den Skill verwenden, wenn eine Windows-EXE in einer unterstützten lokalen Linux-Umgebung ausgeführt oder überprüft werden soll. Der Skill stellt dafür Wine und die notwendigen Startskripte bereit.

Die vorbereitete Runtime wird bevorzugt verwendet. Falls sie mit der jeweiligen Umgebung nicht kompatibel ist, kann auf den Build-Fallback zurückgegriffen werden.

Wine ist ein unabhängiges Open-Source-Projekt. Dieses Plugin ist kein offizielles Produkt des Wine-Projekts und kein offizielles Produkt von OpenAI.
