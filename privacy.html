Portable Wine Runner is designed as a local skill plugin that provides a Wine runtime for executing compatible Windows applications in supported environments.

The plugin does not operate its own remote application server and does not intentionally transmit Windows executables, local files, command output, or Wine execution data to the project operator.

1. Scope of this Privacy Policy

This Privacy Policy explains what personal data may be processed in connection with:

  • the Portable Wine Runner website;
  • the Portable Wine Runner plugin and its local execution workflow;
  • email communication with the project operator;
  • third-party platforms used to host, distribute, or run the project.

2. Categories of Data That May Be Processed

2.1 Website access data

When the project website is accessed, the hosting provider may technically process information such as:

  • IP address;
  • date and time of access;
  • requested page or file;
  • browser type and browser version;
  • operating system information;
  • referrer information, if provided by the browser;
  • technical request and security information.

2.2 Email communication

If you contact the project operator by email, the following information may be processed:

  • your email address;
  • your name, if provided;
  • the content of your message;
  • attachments you voluntarily send;
  • technical email metadata.

2.3 Local plugin execution data

Portable Wine Runner may access local files that are required to perform a task requested by the user, for example:

  • Windows executable files;
  • DLL files and runtime dependencies;
  • local directories selected for execution;
  • command-line arguments;
  • standard output and error output;
  • temporary Wine runtime and prefix files.

This data is used locally for execution of the requested task. Portable Wine Runner does not provide a project-operated remote server to which such files or execution results are automatically uploaded.

3. Purposes of Processing

Data is processed only where necessary for the following purposes:

  • providing and securing the project website;
  • responding to support or other email requests;
  • executing compatible Windows applications through Wine;
  • creating temporary runtime files required by Wine;
  • diagnosing execution errors when explicitly requested by the user;
  • maintaining the security and technical integrity of the project;
  • complying with applicable legal obligations.

Personal data is not used by the project operator for targeted advertising, behavioral profiling, or the sale of personal information.

4. Recipients and Third Parties

The project operator does not sell personal data.

Depending on how you access or use the project, data may be processed by the following independent service providers:

4.1 GitHub

The website and source code may be hosted through GitHub and GitHub Pages. GitHub may process technical access and security data in accordance with its own privacy policy.

4.2 OpenAI / ChatGPT / Codex

If Portable Wine Runner is used through ChatGPT, Codex, or another OpenAI environment, information submitted to or generated within that platform may be processed by OpenAI according to the user's account settings, applicable agreements, and OpenAI's privacy policies.

Portable Wine Runner itself does not operate an additional remote backend that receives this data.

4.3 Email provider

If you contact the project operator by email, the email provider used by the sender and recipient may process email content and metadata as necessary to deliver the message.

4.4 Other recipients

Information may also be disclosed where required by law, court order, or another binding legal obligation.

5. Data Retention

5.1 Plugin execution data

The project operator does not operate a remote storage service for Portable Wine Runner execution data.

Local runtime files, Wine prefixes, caches, logs, and temporary files may remain on the user's local or sandboxed environment until they are deleted by the user, the host environment, or an automated cleanup process.

5.2 Email correspondence

Email correspondence is retained only for as long as reasonably necessary to respond to the request, maintain relevant support history, resolve disputes, or comply with applicable legal obligations.

Where no longer required, such correspondence may be deleted.

5.3 Website logs

Website access and security logs are primarily controlled by the website hosting provider. Their retention periods are determined by the respective provider's policies and security requirements.

6. User Controls and Choices

Users have control over the data they provide to Portable Wine Runner and may:

  • choose which Windows executable or local file is used;
  • avoid providing files that contain sensitive information;
  • stop execution at any time where supported by the host environment;
  • delete local Wine prefixes, caches, logs, and temporary runtime files;
  • remove or uninstall the plugin;
  • avoid contacting the project operator by email;
  • request correction or deletion of personal data provided directly by email;
  • use privacy and data controls provided by GitHub, OpenAI, or other platforms.

Requests concerning personal data held directly by the project operator may be sent to tarekwasfy01@gmail.com .

7. Cookies, Analytics, and Advertising

The project website does not intentionally use its own advertising cookies, behavioral tracking tools, or analytics services such as Google Analytics or Meta Pixel.

Third-party hosting platforms may use technically necessary mechanisms in accordance with their own policies.

8. Security

Reasonable technical and organizational measures are used to reduce the risk of unauthorized access, alteration, disclosure, or loss of information under the direct control of the project operator.

Running executable files can present security risks. Users should only execute Windows applications from sources they trust. Portable Wine Runner does not guarantee that third-party executables are safe.

9. International Data Processing

Third-party providers such as GitHub, OpenAI, or email providers may process information in countries outside the user's country of residence.

Such processing is governed by the respective provider's privacy policy, contractual arrangements, and applicable data protection safeguards.

  • Article 6(1)(c) GDPR, where processing is necessary to comply with a legal obligation;
  • Article 6(1)(a) GDPR, where consent is specifically requested.
